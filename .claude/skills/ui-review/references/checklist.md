# UX pass prompts

Use per page after the measurements. Each prompt is answered from the running page, not from the source. Record failures as items with evidence (what you did, what happened, screenshot path).

## Main task
- What is the one thing a visitor comes to do on this page? Click through it from the first screen: how many steps to finish?
- Is the primary action visible without scrolling at 375 and 1440? Is there one primary action, or several of equal weight?

## Copy and labels
- Does each CTA name the outcome ("Create account", not "Submit" or "Get started")?
- Is one label used for one intent, and are two different actions never given the same label?
- Any placeholder text (lorem ipsum, "TODO", "Your text here"), hype words, or invented figures?

## Forms
- Every field has a visible label (not only a placeholder).
- Errors appear beside the field, name the problem and the fix, and do not rely on colour alone.
- Input is kept after a failed submit. Required and optional fields are marked.

## States
- Empty: does it say what is missing and give the next step?
- Loading: is there feedback, and does the layout stay put?
- Error and offline: can the user recover without reloading?

## Keyboard and focus
- Tab through the whole page. Is the order the visual order? Is the focus ring visible on every control, on every background?
- Can every control be reached and operated without a pointer? Can a menu or dialog be closed with Escape and does focus return?

## Motion
- With reduced motion requested, do animations stop or become short fades?
- Does anything move on its own for more than five seconds with no pause control?
